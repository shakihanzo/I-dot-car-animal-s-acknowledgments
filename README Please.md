# 比較詳細的誌謝

## 致我那同儕

軒立，很難想像一個人身上會同時具備3D列印、強化學習、果乾、汽車、美甲、網路、祕書、攝影等多項知識，我從未見到知識面如此廣泛的人，我從軒立身上學到了非常多以前從未接觸過的事物，能認識你，是我的榮幸。

祐民，總是在我感到困擾的時候與我分享並幫助我解決問題，我從祐民身上學到太多東西了，如果學這些東西要繳學費，那將是一筆天文數字。

睿淼，非常的講義氣，是真正的兄弟。很多時候就差推一把，而睿淼就是那隻手。

智雍，我很佩服他的行動力與能力，同時也很感謝他在課程上的幫助，沒有他，我可能拿不到這些學分，但我永遠不會忘記你害我翹課漏掉點名。

## 學長

昱丞，總是願意和我們分享並指引我們關於未來的方向，咖啡很好喝，且我目前只認這一味，但英雄聯盟依舊是個壞文明。

仁暐，願意一起發瘋、分享學術上的經驗，而且為人正直，實乃吾輩楷模。

漢霖，永遠的實驗室傳奇，他的存在是我們的一大心靈支柱，ES711(雖然現在是ST730)不能沒有漢霖，就像西方不能失去耶路撒冷。

## 學弟妹

閔翔，做了一個超級好看的投影片模板，乾淨又舒服，同時不失專業感，我真的很喜歡那個模板 ; 陪我一起打APEX，雖然我菜到出水，但仍願意陪我玩，雖然我每次都第一個倒，但你從不嫌棄，這是何等的寬容大量 ; 幫我3D列印我做的各種小垃圾，儘管他看起來就是一坨，但仍願意給我試錯的機會 ; 在口試時幫我紀錄各項問題與重點，方面我後續的修改 ; 半夜肚子餓的時候總是揪的到人陪我出去吃宵夜，其貢獻族繁不及備載，偉大，無需多言，但也希望你在關心別人的同時，也要關心自己。

雅佳，謝謝論文監工的持續督促，讓我能準時產出我的學術黃金，同時極大程度的為我們解決世紀難題：晚餐吃什麼。

陳緯，是一個很正向的人，還記得我口試那天，他在下面向我比加油手勢，結束後還會稱讚我，我真的很感動，現在想起來依舊振奮人心。

宇軒，雖然互動不多，在實驗室的工作上總是不留餘力，我能感受到，實驗室沒你會垮。

蕙岑，我的獎勵型人格最大分靈體之一，是漂亮飯與國宴級美食百科全書，是你讓我對早餐有全新的認知，謝謝你。


早知道要謝那麼多我就直接謝天了
