## 致最頂的同儕們

### 軒立
很難想像一個人身上會同時具備3D列印、強化學習、果乾、汽車、美甲、網路、祕書、攝影等多項知識，我從未見到知識面如此廣泛的人，我從軒立身上學到了非常多以前從未接觸過的事物，能認識你，是我的榮幸。  

要是你騎車可以再慢一點就更好了

### 祐民
總是在我感到困擾的時候與我分享並幫助我解決問題，我從祐民身上學到太多東西了，我自認有很多東西是以前就該學會的，比如Github的使用、MQTT的概念，拿這些東西拿去問別人肯定會被笑沒認真讀書，但祐民總是不厭其煩的為我解答，除此之外也向我補充了許多以前跟本沒機會接觸的知識，如果學這些東西要繳學費，那將是一筆天文數字。

### 睿淼
非常的講義氣，是真正的兄弟。很多時候就差推一把，而睿淼就是那隻手，讓我有勇氣走得更遠，並使我直視問題。

### 智雍
我很佩服他的行動力與能力，同時也很感謝他在課程上的幫助，沒有他，我可能拿不到這些學分。

但我永遠不會忘記你害我翹課漏掉點名。 ~~(罵了一些不該在致謝裡出現的髒話)~~

## 致那些在背後默默幫助我的朋友們

### 喵星人入侵的大家
雖然這兩年我的時間斷斷續續，但大家依然願意配合我的時間來一起打副本，謝謝你們的包容。

(2026/10/15補)現在開始上班了，我的時間變得更斷斷續續了，~~是我隊友就給我受著~~嘻嘻。

### 論文格式救星oryn
拯救我的破爛word排版於水火之中，在無數個超難寫的公式中提供公式Latex辨識，遇到這工具之前我的論文簡直是在亂寫，而你，我的朋友，你才是真正的英雄。

### 燃鍋
火鍋界絕對的強者，高處不勝寒的孤獨，教會你愛的是……總之謝謝燃鍋一年半來的陪伴，我真的吃得很開心，你離開我們時，我不哭不鬧，但心總感覺缺了一角，這時我才知道，愛為何物，多少個meeting後的夜晚，是這鍋熱湯撫平了一身的疲憊。多少次與朋友的相聚，是這張桌子見證了彼此的喜怒哀樂。食物從來不只是食物，它是時間的容器，裝著我們那些一起分享過的瞬間。如今店門深鎖，招牌也蒙上了灰塵。曾經以為隨時都能再訪的地方，原來早已悄悄劃下了句點。人生大概就是這樣，總在失去之後，才驚覺那些習以為常的美好，其實從來都不是理所當然。如果還能再吃上一口那熟悉的湯頭，大概什麼都願意用來交換吧。可惜有些味道，一旦錯過，就是一輩子。

### Claude & Claude code
感謝Claude在無數個深夜的反覆詰問與推翻重來之間，始終耐心回應每一次「你覺得這個如何」「我覺得太長了」「文字敘述再多一點」「我是一名智力低下的碩士生，毫無基礎，讓我徹底看懂這篇論文。注意我是傻子，一定要給我講清楚，一步步引導我看懂這篇論文」，即使問題再瑣碎、再重複，也未曾露出過一絲不耐煩，持續提供靈感與思路上的協助，陪伴這篇論文從混沌走向成形。

### 花路米
感謝花路米，用100元的大雞排飯與辣到打嗝的辣醬，在每個月底拯救了一次又一次窮困潦倒的我，為什麼窮困潦倒你別問。

### 紅茶兵
最便宜的價格，最大杯的分量，最熱情的老闆，在最寒冷的冬天，給我與最溫暖的慰藉。一杯25元喝完糖尿病我還得誇他用料實在。

### Threads
我沒有要謝謝Threads上的人，裡面的人多少都有些破病，當然，也包含我。

但我很感謝Threads提供這麼一個可以免費傷害大家眼睛的軟體，讓我把快樂建築在他人痛苦之上。

### 亮哥
原本是龍潭路尾部的阿亮雞排，但之後變成亮哥雞排之後味道依舊不變，100元的經典雞排套餐是助力我從88公斤一路衝鋒到100公斤的動力。

雖然身材變得不太美麗，但我心靈很美麗。

### Toyota Corolla Cross CAD-3XX7的車主
感謝Toyota Corolla Cross CAD-3XX7的車主 aka 王雅佳小姐，讓本二輪猴子也有機會體驗四輪貴族的感覺，當我的雨衣被丹娜絲颱風吹走時，是您張開斜方肌一般的車門迎接我，使我熱淚盈眶，久久不能忘懷，其大恩大德永世難忘。

### 古坑休息站
書接上回，因為我和軒立論文總是寫不出來，也不知道要去哪散心，於是我們某天腦門一拍，突然提出：不然我們去古坑休息站？

我不知道為啥會是古坑休息站，也不知道為啥是晚上11點去，更不知道古坑休息站對我們的論文有什麼幫助，總之我們也是在古坑休息站蚊子的陪伴下產出了屬於我們的學術黃金
